# 論文檢查器 (thesis_checker) 📝

這是一個利用 Python 開發的論文格式與內容檢查工具。透過圖形化介面，使用者可以輕鬆上傳 PDF 檔案並自動偵測潛在問題。


## 📦 安裝與執行步驟

請按照以下步驟在您的本機電腦上架設並執行本專案：

### 1. 建立並啟用虛擬環境
```bash
# 建立虛擬環境
python -m venv .venv

# 啟用虛擬環境 (Windows Windows PowerShell)
.\.venv\Scripts\Activate.ps1
```

### 2. 安裝依賴套件
```bash
pip install -r requirements.txt
```

### 3. 執行程式
```bash
python main.py
```
